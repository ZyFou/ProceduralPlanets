procedural-planets examples

Run npm run dev and open these pages. Each imports procedural-planets like your code would.

  • viewer.html — PlanetViewer: a planet on a page in a few lines, every preset.
  • embed-solar-system.html — Planet + PlanetRenderer inside an existing scene: star, planet, ringed giant, ordinary meshes occluding and occluded.
  • composer.html — PlanetPass in an EffectComposer chain with bloom and OutputPass.
  • baked.html — bakePlanet(): static meshes with baked textures and standard materials.
